# Cafe Ordering Program (C)

A console program that shows coffee, tea and donut menus, takes an order item by item, and prints the total bill. Written as an early C exercise.

## What it practices

- Structs (`MenuItem` with a name and price)
- Arrays of structs passed to functions
- Input validation and clearing the input buffer
- Function decomposition (`displayMenu`, `getChoice`, `orderMenu`)

## Build and run

```bash
gcc Cafe.c -o cafe
./cafe
```
